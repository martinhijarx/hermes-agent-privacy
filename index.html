Hermes Agent Privacy Policy

Last updated: September 1, 2026

Hermes Agent is a private, personal-use application operated by Martín Híjar. It connects Martín’s own WHOOP account to a local coaching workflow on his Mac.

Data accessed

The application requests read-only access to WHOOP recovery, physiological cycles, sleep, and workout data. It does not request profile or body-measurement access and does not write data back to WHOOP.

How data is used

Data is used solely to provide personal training context, such as comparing recovery and sleep with a privately maintained training plan.

Storage and sharing

OAuth credentials are stored in the macOS Keychain. Cached fitness data remains on the user’s Mac. WHOOP data is not sold, rented, advertised against, or shared with third parties.

Retention and deletion

Local cached data may be replaced during synchronization. Access can be revoked at any time from WHOOP, and local credentials and cached data can be deleted on request.

Security

The application uses WHOOP’s documented OAuth 2.0 and API v2 mechanisms. Secrets are not stored in source control or public documents.
